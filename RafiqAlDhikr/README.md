# رفيقك في الذكر (Rafiqak fi Al-Dhikr)

تطبيق أندرويد أصلي بالكامل (Native Android) مبني بلغة **Kotlin** وواجهة **Jetpack Compose** مع **Material 3** وقاعدة بيانات **Room** وتفضيلات **DataStore** وجدولة إشعارات محلية موثوقة.

## المميزات الأساسية
- **واجهة عربية كاملة (RTL)** بتصميم هادئ ومريح للعين يدعم الوضع الفاتح والداكن وتخصيص الشاشة الرئيسية.
- **ملفات شخصية متعددة ومعزولة تماماً** على نفس الجهاز دون حسابات أو تسجيل دخول أو اتصال بالإنترنت.
- **الأذكار اليومية**: الصباح، المساء، النوم، الاستيقاظ، والأذكار العامة، بنصوص موثقة ومصادر واضحة مع إمكانية إضافة وتعديل الأذكار وتخصيص تذكير كل قسم.
- **ورد القرآن الكريم**: أهداف بالصفحات أو الأحزاب أو الأجزاء أو وحدات مخصصة، مع سجل القراءة والإحصاء الأسبوعي والشهري.
- **حفظ القرآن ومراجعته**: خطط متعددة حسب السورة ونطاق الآيات (١١٤ سورة كاملة) مع جدولة وتذكيرات مستقلة للحفظ والمراجعة.
- **الصيام والتقويم الهجري**: تقويم شهري يجمع الهجري والميلادي (الإثنين والخميس، الأيام البيض، عرفة، عاشوراء، ست من شوال) مع ضبط يدوي لفرق الأيام حسب رؤية الهلال.
- **العبادات والنوافل والأهداف المخصصة**: الضحى، قيام الليل، الصدقة، صلة الرحم، بر الوالدين، سنن الجمعة، والأهداف اليومية والأسبوعية المخصصة (جميعها اختيارية).
- **المسبحة والاستغفار**: عدّاد إلكتروني كبير بحفظ تلقائي للأرصدة اليومية وسجل الأيام السابقة وزر تصفير بتأكيد.
- **دفتر الأدعية الشخصي**: حفظ محلي خاص مع التصنيفات والمفضلة والبحث الفوري.
- **المواسم الإسلامية**: رمضان، العشر الأواخر، عشر ذي الحجة، عرفة، عاشوراء، الأشهر الحرم، وموسم الحج.
- **نظام التنبيهات والعبادات الفائتة**:
  - دعم الجداول اليومية والأسبوعية وأيام الأسبوع المحددة والمواعيد الفردية والتكرار المخصص.
  - أزرار غفوة (١٥ د) وتذكير بعد ساعة وإعادة جدولة مخصصة.
  - **ضمان صارم**: عند فوات وقت النشاط يُسجَّل كـ «فائت»، وإعادة جدولة التذكير **لا تحسبه مكتملاً أبداً** حتى يضغط المستخدم على «تم الإنجاز».
  - استعادة التذكيرات بعد إعادة تشغيل الجهاز أو تحديث التطبيق.
- **النسخ الاحتياطي والاستعادة المحلية**: تصدير واستيراد ملف JSON محلي مع التحقق من سلامة البيانات (SHA-256) وتأكيد الاستعادة.
- **الخصوصية**: لا يطلب التطبيق إذن الإنترنت (`INTERNET`) أو الموقع أو الكاميرا أو الميكروفون؛ يعمل محلياً بالكامل.

## متطلبات البناء والتثبيت
1. Android Studio Ladybug (أو أحدث) مع JDK 17 و Android SDK Platform 35.
2. افتح مجلد `RafiqAlDhikr` في Android Studio.
3. لبناء ملف APK عبر سطر الأوامر:
   ```bash
   ./gradlew testDebugUnitTest assembleDebug
   ```
4. سيكون ملف الـ APK الناتج في:
   `app/build/outputs/apk/debug/app-debug.apk`
5. لتثبيت التطبيق على جهاز أندرويد متصل:
   ```bash
   ./gradlew installDebug
   ```
